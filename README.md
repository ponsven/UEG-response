# UEG-response: Linear and nonlinear response theory for uniform electron gas systems

Implementations of the ideal linear and quadratic response functions for fermions, 
to construct approximate models for the density response of the Uniform Electron Gas (UEG).

## Reference
The detailes of the methods used in this package are provided in:

> Pontus Svensson, Jan Vorberger, Zhandos A. Moldabekov, Panagiotis Tolias, Paul Hamann, Xuecheng Shao Cheng Ma, Tobias Dornheim, The Quadratic Density Response Function for Non-Interacting Fermions at Arbitrary Temperature, *In preperation*

Cite this manuscript when using this package.

## Installation

To use *UEG-response*, first install the package locally:

* [Optional] Activate the virtual enviroment where the *UEG-response* should be installed.
* [Initial build] For the initial build you might need to install `build`:

```
    python -m pip install --upgrade build
```

* Build and install *UEG-response*:

```
    python -m build
    python -m pip install -e .
```
